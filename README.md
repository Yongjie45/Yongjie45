# 📝 Jasper待办 (Jasper Todo List)

一个纯原生 HTML/CSS/JS 编写的现代化待办事项应用。无需任何框架，专注于数据驱动与流畅的用户体验。

## ✨ 功能特性

- **增删改查**：快速添加任务，支持删除与完成打勾。
- **日期管理**：支持为任务添加截止日期。
- **无缝编辑**：双击任务文字即可直接编辑（支持多行），回车或点击空白处保存。
- **本地存储**：使用 `localStorage` 实现数据持久化，刷新页面不丢失。
- **智能筛选**：支持「全部」「未完成」「已完成」视图切换。
- **FLIP 动画**：删除中间项时，下方的任务会像 iOS 列表一样平滑上移。

## 🛠️ 技术栈

- **HTML5**：语义化标签，原生 `datetime-local` 日期选择器。
- **CSS3**：Flexbox 布局，自定义滚动条，平滑过渡动画。
- **JavaScript (ES6+)**：
  - 数据驱动视图（基于数组重新渲染 DOM）。
  - `contenteditable` 实现无感编辑。
  - 事件监听与全局点击失焦处理。
  - **FLIP 技术**（First-Last-Invert-Play）实现丝滑列表动画。

## 🚀 快速开始

由于这是一个纯前端项目，无需安装任何依赖。

1. 克隆或下载本项目到本地。
2. 使用 VS Code 的 Live Server 插件，或者直接双击 `index.html` 在浏览器中打开。
3. 开始规划你的每日任务吧！
